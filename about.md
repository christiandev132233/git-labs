## Summary
Adds an About page explaining the purpose of my Git & GitHub Lab, created through hands-on CoderCo exercises.

## Project overview
This project demonstrates Git workflows, including creating branches, staging and committing changes, resolving merge conflicts, reverting commits, and pushing updates to GitHub. It also includes pre-commit checks and documentation of the exercises.

## Purpose
Give visitors an overview of the repository and the version-control skills practised through the project.
